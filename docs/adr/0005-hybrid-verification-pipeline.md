# ADR-0005：采用图算法、抽象分析与局部 SMT 精化的混合验证

- **状态：** Proposed
- **决策域：** 形式化验证

## 背景

经济死锁、状态机冲突和数值极值具有不同的量词、时间和数值语义。全图 SMT 会放大编码错误和性能风险；单纯 SCC/区间分析又不足以确认顺序、库存和联合转移。

## 备选方案

1. 全部图谱直接编码为一个 SMT 问题。
2. 仅使用图遍历、SCC 和静态规则，不使用求解器。
3. 直接采用无界模型检查/随机博弈作为 MVP 主路径。
4. 结构预筛 → 区间/抽象分析 → 有界 SMT 局部精化，并保留多结果协议。

## 决策

采用方案 4。图算法发现候选，抽象域做便宜过近似，受限 `QF_LIA`/`QF_BV` 有界 SMT 负责难点精化；语义缺失时返回 `not-modeled`，超时返回 `unknown`。

## 理由与边界

- 将求解器规模限制在具有来源映射的局部模型；
- 区分资源流、可执行序列和策略/环境量词；
- 可明确报告有界无反例而不冒充全局证明；
- MVP 不能处理全部无界、概率和策略性质；
- SCC/LP/区间结果都不能越权成为全局安全结论。

## 推翻条件

- 受控工作负载证明全图求解在相同正确性和资源预算下更简单且更可靠；
- 需求转为必须验证无界或随机博弈性质，且已有可复现后端与语义合同；
- 抽象层假阳性使人工审核成本高于直接精确模型，且存在可证明替代。

## 影响

必须设计 Rule IR、source map、近似方向、边界 `k` 和结果状态；solver worker 使用私有 context，性能按理论片段实测。
