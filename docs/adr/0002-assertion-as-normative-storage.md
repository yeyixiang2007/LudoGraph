# ADR-0002：以独立 Assertion 作为规范断言存储

- **状态：** Proposed
- **决策域：** 断言生命周期与溯源

## 背景

直接把 claim 存为图关系便于一跳遍历，但同一端点可能存在不同来源、版本和相互冲突的事实；证据、状态、修订和多值限定也需要独立生命周期。

## 备选方案

1. 只存 canonical 直接边，更新时覆盖。
2. 只存关系属性，允许平行关系但由应用层维护历史。
3. 以独立 Assertion 记录/节点为规范存储，直接边只做物化热点投影。

## 决策

采用方案 3。每条断言是一个一等实体，有确定性 ID、证据、certainty、status、revision 和 supersedes；直接边可重建但不能替代规范历史。

## 理由与边界

- 冲突不覆盖，满足来源和版本审计；
- `certainty`（原文语气）与 `status`（生命周期）可以独立变化；
- 求解器和查询结果可以回指统一断言实体；
- 代价是规范读取多一跳，热点查询可用物化视图缓解；
- 物化视图的双写/重建一致性必须有测试。

## 推翻条件

- 真实查询分析证明断言跳数在目标场景不可接受，且另一种规范存储仍能保留完全等价的历史语义；
- 后端提供经验证的原生多重关系版本/证据模型，能等价满足冲突、修订和回指要求；
- 数据范围被严格限定为永不修订、无冲突的只读事实（须重新评估需求）。

## 影响

导入必须幂等；查询需支持当前视图和历史视图；Assertion 到原文的 provenance 是强门槛。
