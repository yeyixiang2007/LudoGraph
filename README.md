# LudoGraph

面向游戏工业级规则验证的**非对称神经-符号架构**（Asymmetric Neuro-Symbolic Architecture）。

## 架构概要

```text
非结构化游戏策划文档
        │
        ▼  ① 本体受限抽取（Ontology-Constrained Extraction）
   LLM 思维链推理（CoT）
        │
        ▼
   LudoGraph — 领域特定的可计算知识图谱
        │
        ▼  ② 实时意图路由与查询编译（NL2Cypher Router）
   端侧微调 SLM
        │
        ▼  ③ 静态形式化验证（Static Formal Verification）
   Z3 SMT 可满足性模理论 + 图遍历算法
        │
        ▼
   出厂即正确（Correct-by-Construction）的自动化审查防线
```

## 三层职责

| 层 | 做什么 | 关键手段 |
| --- | --- | --- |
| **抽取层** | 把非结构化策划文档变成可计算知识图谱 | 本体受限抽取、思维链推理、原文证据留存 |
| **路由层** | 把自然语言查询编译为图查询 | 端侧微调 SLM、意图路由、NL2Cypher |
| **验证层** | 静态形式化验证 | Z3 SMT、图遍历算法 |

## 目标检测类别

- **经济死锁** — 资源循环依赖、无法达成的产出/消耗闭环
- **状态机冲突** — 互斥状态同时成立、状态转换不可达
- **数值极值** — 属性越界、数值爆炸或归零

**性能目标**：高并发、毫秒级响应。

## 设计立场

事实保存在**图谱或检索层**，语言模型只负责**抽取、查询翻译和基于证据的表达**。

- 模型不把策划案事实记入参数
- 抽取时**不补写**原文没有说的因果、数值换算或实体身份
- 每个查询结果都能**回到原文来源检查**，而不是只得到一个无法审计的三元组
